## 🌃 Sobre la práctica · El expediente SmartToll

Este repositorio contiene nuestra práctica académica de programación, enfocada en el desarrollo de una solución para la administración de un peaje.

## 📋 1. Descripción del ejercicio

Desarrollar un programa denominado **SmartToll: Peaje**, que permita registrar los vehículos que pasan por un peaje y calcular el valor correspondiente según el tipo de vehículo.

El programa solicitará inicialmente la cantidad de vehículos que se van a procesar. Después, por cada vehículo, deberá registrar la placa, el tipo de vehículo, el número de ejes y la hora.

El sistema utilizará una estructura `switch` para seleccionar la tarifa correspondiente al tipo de vehículo y aplicará validaciones para evitar datos incorrectos.

Al finalizar el registro, se generará un reporte con el total recaudado, la cantidad de camiones con más de cuatro ejes y la placa del vehículo que pagó el importe más alto.

## 🎯 2. Objetivo

Desarrollar un programa en Java que permita registrar y procesar los datos de varios vehículos en un peaje, utilizando ciclos, estructuras condicionales, `switch`, validaciones, contadores y acumuladores para calcular tarifas y generar estadísticas.

## 📝 3. Datos de entrada

Por cada vehículo se solicitarán los siguientes datos:

| Dato | Descripción |
| :--- | :--- |
| **Placa** | Identificación del vehículo. |
| **Tipo de vehículo** | Opción 1: motocicleta, opción 2: automóvil, opción 3: camión. |
| **Número de ejes** | Cantidad de ejes del vehículo. |
| **Hora** | Hora de registro del vehículo. |

### 🚘 Tipos de vehículos

| Código | Tipo |
| :---: | :--- |
| **1** | Motocicleta |
| **2** | Automóvil |
| **3** | Camión |

## ⚙️ 4. Funcionamiento del programa

El programa deberá seguir esta secuencia:

1. Solicitar la cantidad de vehículos que se registrarán.
2. Validar que la cantidad sea mayor que cero.
3. Iniciar un ciclo para procesar cada vehículo.
4. Solicitar la placa del vehículo.
5. Solicitar el tipo de vehículo.
6. Solicitar el número de ejes.
7. Solicitar la hora de registro.
8. Validar los datos ingresados.
9. Utilizar `switch` para seleccionar la tarifa según el tipo de vehículo.
10. Calcular el importe que debe pagar el vehículo.
11. Acumular los valores recaudados.
12. Contabilizar los camiones que tengan más de cuatro ejes.
13. Identificar la placa correspondiente al mayor importe pagado.
14. Mostrar el reporte final del peaje.

## 💰 5. Tarifas del peaje

El enunciado proporcionado no especifica los valores monetarios de las tarifas. Por ello, deberán utilizarse los valores establecidos por el docente o acordados por el equipo.

| Tipo de vehículo | Tarifa |
| :--- | :--- |
| Motocicleta | Definir en el programa. |
| Automóvil | Definir en el programa. |
| Camión | Definir en el programa. |

La selección de la tarifa se realizará mediante `switch`.

**Importante:** si la hora implica un recargo o una tarifa especial, esa regla también deberá definirse antes de programar el cálculo. No se debe asumir un recargo que no esté especificado.

## 📊 6. Reporte final

Al terminar de procesar los vehículos, el programa deberá mostrar un reporte con la siguiente información:

```text
========================================
          SMARTTOLL - PEAJE
========================================
Total de vehículos procesados:
Total recaudado:
Camiones con más de 4 ejes:
Placa con mayor importe pagado:
========================================
```

## 🧩 7. Estructuras utilizadas

| Estructura o recurso | Aplicación |
| :--- | :--- |
| `Scanner` | Leer los datos ingresados por el usuario. |
| `for` | Procesar la cantidad de vehículos indicada. |
| `switch` | Seleccionar la tarifa según el tipo de vehículo. |
| `if / else` | Validar datos y comprobar condiciones. |
| Contador | Registrar los camiones con más de cuatro ejes. |
| Acumulador | Sumar los importes cobrados. |
| Variable de máximo | Identificar el mayor importe pagado. |
| Variable `String` | Guardar la placa del vehículo con mayor importe. |

## 🛡️ 8. Validaciones

El programa deberá comprobar que:

- La cantidad de vehículos sea mayor que cero.
- La placa no esté vacía.
- El tipo de vehículo corresponda a una opción válida: `1`, `2` o `3`.
- El número de ejes sea mayor que cero.
- La hora se encuentre dentro del formato y rango definidos para el programa.

Para este README se propone ingresar la hora como un número entero entre `0` y `23`. Si la implementación utiliza el formato `HH:mm`, esta validación deberá adaptarse.

Cuando se introduzca un dato inválido, el programa deberá informar del problema y solicitar nuevamente el dato, o rechazar el registro según la lógica implementada.

## 🧪 9. Casos de prueba

Los siguientes casos permiten comprobar el funcionamiento y las validaciones del sistema.

| Caso | Placa | Tipo | Ejes | Hora | Resultado esperado |
| :---: | :--- | :---: | :---: | :---: | :--- |
| **1** | PBA-1234 | 1 | 2 | 8 | Registro válido de motocicleta. |
| **2** | ABC-5678 | 2 | 2 | 14 | Registro válido de automóvil. |
| **3** | TBC-9001 | 3 | 6 | 21 | Registro válido y contador de camiones con más de cuatro ejes incrementado. |
| **4** | XYZ-1234 | 4 | 4 | 10 | Tipo de vehículo inválido. |
| **5** | Vacía | 1 | 2 | 8 | Placa inválida. |
| **6** | ABC-0001 | 3 | 0 | 12 | Número de ejes inválido. |
| **7** | ABC-0002 | 2 | 2 | 24 | Hora inválida bajo el rango propuesto de 0 a 23. |

### 🔬 Prueba de escritorio

Para comprobar el cálculo de la recaudación y la identificación del mayor importe, se deben registrar varios vehículos con tarifas conocidas.

| Vehículo | Tipo | Tarifa aplicada | Acumulado |
| :--- | :--- | :--- | :--- |
| Vehículo 1 | Motocicleta | Según configuración | Suma de la primera tarifa. |
| Vehículo 2 | Automóvil | Según configuración | Suma de las dos tarifas. |
| Vehículo 3 | Camión con más de 4 ejes | Según configuración | Suma de las tres tarifas. |

Los importes definitivos deberán completarse con las tarifas utilizadas en el código del equipo.

## 🎯 12. Conclusiones

1. El ejercicio SmartToll permite aplicar estructuras de control y ciclos para procesar información de varios vehículos de manera organizada.

2. La utilización de `switch` facilita la selección de tarifas según el tipo de vehículo, mientras que los contadores y acumuladores permiten generar estadísticas de recaudación.

3. Las validaciones y los casos de prueba ayudan a detectar entradas incorrectas y comprobar que los cálculos se realicen de acuerdo con las reglas establecidas.

4. La identificación del vehículo con el mayor importe pagado permite practicar la comparación de valores y el almacenamiento de información relacionada, como la placa del vehículo.

5. El desarrollo de este ejercicio fortalece el razonamiento lógico y la capacidad de transformar un problema en una solución organizada mediante instrucciones de programación.
